# Code of Conduct

## Our pledge

We want participation in this project to be respectful, constructive, and welcoming regardless of experience level, identity, or background.

## Expected behavior

- Be respectful and assume good intent.
- Give technical feedback about code and behavior, not people.
- Respect privacy: do not share credentials, personal reports, or machine-specific data.
- Keep security research and discussions lawful and defensive.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, publication of private data, or instructions intended to harm systems are not welcome.

## Reporting

Report conduct concerns privately through the repository owner's GitHub contact. Security vulnerabilities should follow [SECURITY.md](SECURITY.md).

Maintainers may remove, edit, or reject contributions that conflict with this code of conduct.
