# Security Policy

## Supported version

Security fixes are currently provided for the latest release line: **v1.4.x**.

## Reporting a vulnerability

If you believe you found a vulnerability in Atlhas1x itself, do not disclose it in a public issue, discussion, pull request, or report attachment.

Use GitHub's private security reporting for this repository when it is enabled. Include:

- a concise description of the issue and its potential impact;
- affected Atlhas1x version and Windows version;
- reproducible, non-destructive steps or a minimal proof of concept;
- any relevant logs with tokens, paths, user names, IP addresses, and report contents removed or redacted;
- suggested mitigation, if known.

Please do not send malware samples, credentials, private reports, or live access details. Atlhas1x is a local auditing tool; reports may contain information about a machine and should be treated as sensitive.

## Scope

This policy covers the source code, bundled scripts, and project-controlled automation. Findings reported by Atlhas1x about a third-party Windows installation are not automatically vulnerabilities in Atlhas1x.

## Disclosure

Please allow maintainers reasonable time to assess and address a report before public disclosure. Acknowledgement and remediation timelines depend on reproducibility and impact.
