# Images and screenshots

This directory is reserved for redacted project screenshots and documentation images.

Before adding an image, remove or blur usernames, hostnames, report contents, private IP addresses, file paths, tokens, and other machine-specific information. Do not add generated audit reports or screenshots from unredacted development machines.

The existing `assets/banner.png` is the project banner. For the GitHub social preview, use a 1280×640 image that clearly reads **Atlhas1x** and **Windows Security Audit** without including live scan data.
