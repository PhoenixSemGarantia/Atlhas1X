# Atlhas1X

O Atlhas1X será uma ferramenta simples de auditoria de segurança do Windows.

Ela analisará o próprio computador e verificará itens como Windows Defender, Firewall, BitLocker, UAC, usuários administradores, RDP, portas abertas e outras configurações de segurança.

Ao final da análise, o Atlhas1X deverá:

- Mostrar o que está seguro e o que precisa de atenção.
- Dar uma nota de segurança para o computador.
- Explicar os problemas encontrados de forma simples.
- Dar recomendações de como melhorar a segurança.
- Gerar um relatório em HTML ou JSON.

O Atlhas1X não alterará nada automaticamente. A proposta é apenas analisar, avisar e gerar o relatório.
